# Ecological Modelling with R

> *From observation to data, from data to models, from models to ecological understanding.*

Open educational resources for learning ecological modelling through reproducible data analysis with R.

## About

This repository contains teaching materials developed for the course **Ecological Modelling with R**.

The project aims to provide an open and reproducible learning environment for students and researchers interested in ecological data analysis using R.

The course is designed for learners with diverse backgrounds in statistics and mathematics and emphasizes statistical thinking, data visualization, reproducible workflows, and ecological modelling rather than mathematical theory.

🚧 **The course is currently under development.**
